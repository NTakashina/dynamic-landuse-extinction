# dynamic-landuse-extinction

This repository contains a baseline C implementation of a spatially explicit land-use model coupled to species range loss and extinction metrics.

The model describes land-use expansion on a two-dimensional landscape using a reaction-diffusion framework and tracks how habitat conversion affects species distributions, species-area relationships (SAR), and endemics-area relationships (EAR). Protected areas (PAs) can be introduced during the simulation and are treated as non-convertible cells.

This public version corresponds to the baseline parameter set in which species range radii follow a beta distribution with parameters `a = 2` and `b = 10`.

## Files

- `urban_multi.c`  
  Main simulation code.
- `functions.c`  
  Core functions for species initialization, PDE updates, EAR/SAR calculations, and spatial statistics.
- `functions.h`  
  Header file.
- `mt64.h`  
  64-bit Mersenne Twister random number generator.
- `main_result.txt`, `main_95.txt`, `a=2;b=10.txt`, `a=2;b=10_paircorr.txt`  
  Example plotting scripts for processed outputs.

## Requirements

- A C compiler such as `gcc` or `clang`
- GNU Scientific Library (GSL)
- Standard math library (`-lm`)
- `gnuplot` (optional, for visualization)

## Compilation

Example:

```bash
cc -O2 -Wall -Wextra -Wpedantic urban_multi.c functions.c -I. -lgsl -lgslcblas -lm -o urban_multi
```

## Usage

Run:

```bash
./urban_multi
```

The program performs repeated simulations across multiple scenarios and writes output files to the working directory.

## Output

Main output files include:

- `data_result.dat`  
  EAR/SAR summaries as a function of converted area.
- `data_timing.dat`  
  Mean timing of converted-area milestones.
- `data_paircorr.dat`  
  Mean pair-correlation function `g(r)` for PA patterns.
- `data_urban_map.dat`  
  Final land-use / PA landscape snapshot.

Depending on the version used for plotting or debugging, additional intermediate output files may also be produced.

## Model settings

Key numerical and biological settings are defined near the top of `urban_multi.c` and `functions.c`, including:

- grid size
- total simulation time
- time step (`DT`)
- number of trials
- number of scenarios
- diffusion coefficients
- growth rate and carrying capacity
- land-use conversion threshold
- protected-area fraction
- timing of PA introduction

In the baseline code:

- species range radii follow a beta distribution with `a = 2`, `b = 10`
- carrying capacity is `K = 10`
- intrinsic growth rate is `r = 1`
- land-use dynamics are integrated with a fourth-order Runge-Kutta scheme

Alternative parameter sets can be generated by editing the relevant constants directly in the source code.

## Scenario structure

The baseline code includes multiple hard-coded scenarios that differ in:

- the interval between new land-use events
- the land-use fraction at which PAs begin to be established
- the presence or absence of PAs

Scenario definitions are set in `urban_multi.c`.

## Reproducibility and extension

This repository provides the baseline implementation for the `a = 2`, `b = 10` case. Other parameter combinations used in the study can be reproduced by modifying the relevant constants in the source code.

The included gnuplot scripts are examples used for figure generation and may require minor adjustment depending on the desired layout or local file organization.
